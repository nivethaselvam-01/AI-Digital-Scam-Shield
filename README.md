# 🛡️ AI-Powered Digital Scam Shield

An AI-powered web application designed to detect and analyze digital scam messages using Machine Learning.

## 📌 Project Overview

Digital scams such as phishing, banking fraud, OTP scams, prize scams, and fake job offers are increasing rapidly.

The **AI Digital Scam Shield** helps users identify potentially suspicious messages by analyzing the content and detecting common scam patterns.

## ✨ Features

- 🔍 AI-powered scam message detection
- 🚨 Risk level classification
- 📊 Risk percentage visualization
- 🏷️ Scam type identification
- ⚠️ Red-flag detection
- 💡 Safety recommendations
- 📋 Scan history
- 📱 Responsive design for mobile and desktop
- 🧠 Machine Learning-based prediction

## 🧠 Scam Categories

The system can identify different types of suspicious messages, including:

- Phishing scams
- Banking scams
- OTP scams
- Prize scams
- Job scams
- Safe messages
